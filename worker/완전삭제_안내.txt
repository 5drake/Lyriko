====================================================================
  Lyriko - 무설치 포터블 로컬 GPU 워커 안내
====================================================================

[사용 방법] (Windows 10/11 64-bit 전용)
1. 이 ZIP 파일의 압축을 원하는 영문 경로(예: C:\Lyriko-Worker)에 풉니다.
2. 폴더 안의 `Lyriko-Worker.bat` 파일을 더블클릭해 실행합니다.
   - "Windows의 PC 보호"(SmartScreen) 파란 창이 뜨면 `[추가 정보]` → `[실행]` 을 눌러 진행하세요.
     (서명되지 않은 개인 배포 파일에서 나타나는 정상 안내입니다.)
   - 처음 1회 실행 시 아래 환경이 **이 폴더 내부에만** 자동 구성됩니다. (약 3~5분 소요, 완료될 때까지 창을 닫지 마세요 / 2회차부터 즉시 실행)
     · PC에 Node.js(20+)가 없으면 포터블 Node.js 22 LTS(`.\node\node.exe`) 자동 다운로드
     · 포터블 Python AI 실행 환경(`.\python`) 자동 설치
   - 방화벽·네트워크 제한으로 자동 다운로드가 막힐 경우:
     https://nodejs.org 에서 LTS 버전을 설치하거나, 터미널에서
     `winget install OpenJS.NodeJS.LTS` 실행 후 다시 `Lyriko-Worker.bat`를 실행하세요.
   - 서버 주소: http://127.0.0.1:3840 (로컬 루프백 전용)
3. 브라우저에서 Lyriko 웹페이지를 열면 상단 우측의 워커 상태가
   자동으로 초록색(GPU 워커 연결됨)으로 바뀌며 내 PC의 GPU로 작동합니다.

[PC 최소 / 권장 사양 (로컬 GPU 워커)]
- OS           : Windows 10 / 11 (64-bit)
- GPU          : 최소 NVIDIA GTX 16 / RTX 20 이상 (VRAM 6 GB+, 최신 드라이버)
                 권장 RTX 3060 (8~12 GB) 이상
                 *(NVIDIA GPU가 없어도 CPU 모드로 동작 가능하나 4분 곡 기준 수 분 소요)*
- RAM          : 최소 8 GB / 권장 16 GB 이상
- 여유 저장공간: 최소 10 GB / 권장 15 GB 이상
                 *(PyTorch CUDA + AI 모델 약 1.8 GB + Node.js/Python + 임시 캐시 포함)*
- AI 예상 시간 : 4분 곡 기준 RTX 3060 약 30~45초 · RTX 5090 약 10~15초
                 *(최초 1회 AI 모델 다운로드 시간 제외)*

[종료 방법]
- 실행 중인 `Lyriko-Worker.bat` 검은 창에서 X 버튼을 눌러 창을 닫으면
  즉시 백그라운드 프로세스 없이 완전히 종료됩니다.

[완전 삭제 방법 (흔적 0개)]
- 본 프로그램은 Windows 설치 목록, 레지스트리, 사용자 AppData 폴더에
  어떠한 설정이나 모델 파일도 저장하지 않습니다.
- 워커 창을 닫은 뒤, **압축을 푼 이 폴더를 통째로 삭제(휴지통)**하시면
  다운로드된 Node.js·Python·AI 모델·임시 음원·캐시까지 100% 깔끔하게 삭제됩니다.
